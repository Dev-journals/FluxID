# GrantFox OSS — Screenshot / Evidence

Put all visual proof for your QA issue here, in a **subfolder named after your issue**.

## Naming

```
docs/grantfox-OSS/<issue-slug>/
```

Examples:

- `issue3-QA_dashboard_QA/`
- `issue7-QA_analytics/`
- `issue10-QA_agent_contract/`

## What goes inside

- Before/after screenshots (every bug needs its own screenshot)
- Transaction-hash evidence screenshots (Agent Gateway, on-chain save, transfer)
- Mobile + desktop captures where required

## Rules

1. Create your own subfolder — don't dump files at the repo root.
2. Reference paths relatively from your QA-report markdown.
3. Real screenshots only. Fabricated or recycled screenshots = closed PR + ban.
